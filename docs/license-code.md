# 授权码（一人一码）说明

> 面向使用者与管理者。技术实现见 `src/domain/licenseCode.ts`。

---

## 一、这是什么

给"签到插件"用的解锁凭证。**一个人一个码，不能转借。**

```
优学院页          首页 → 设置
┌──────────┐     ┌──────────────────┐
│ 课件 ✓   │     │ 签到插件  🔒 未解锁 │
│ 作业 ⏳  │ ──→ │ [填授权码______]  │
│ 签到 🔒  │     │      [解锁]       │
└──────────┘     └──────────────────┘
```

**没码的时候**，优学院页只有课件和作业，看不到签到。
**填对码之后**，签到插件出现。

---

## 二、码长什么样

```
LK1-5KYX2-LS3F2-222MY-LT6PR-QLWUL-PNW
```

- 以 `LK1-` 开头
- 后面是 5 位一组的分段
- **没有 `0` `1` `I` `O`** —— 这四个字符容易抄错，被移出了字母表

**输入容错**：大小写、空格、漏掉横线，都能正确识别。

---

## 三、为什么不能转借

码里嵌了**你的学号的哈希**。App 解锁时会：

```
码里的学号哈希   ←→   当前登录账号的学号算出的哈希
      相同 → 解锁
      不同 → 拒绝，提示「这个授权码不属于当前账号」
```

**所以别人拿到你的码也白搭。** 这条已用 50 组交叉测试验证过，没有一组错配。

---

## 四、怎么拿码

**找管理员（目前是你自己）。** 流程：

```
① 你打开 web/license-admin.html（双击就行，不用联网）
② 填「姓名 + 学号」，可选填有效期
③ 点「生成授权码」
④ 把码复制给对方（微信/QQ 都行）
⑤ 对方在 App「首页 → 设置」里填入 → 解锁
```

**页面上的列表**保存已生成的记录，存在浏览器本地。建议定期用「导出 JSON」备份。

**好消息**：码是**由学号算出来的、确定性的** —— 同一个学号永远生成同一个码。
所以列表丢了也不影响，重新输学号就能再生成一次。

---

## 五、有效期

生成时可以填一个日期。到期后：

- App 会显示「授权码已过期」
- 签到插件自动锁回去
- 需要重新要一个码

**不填就是永久有效。**

---

## 六、能撤销吗

**不能远程撤销。** 因为校验是**本地**做的，不需要联网。

如果要撤销某个人的码，只有两个办法：

| 办法 | 代价 |
|---|---|
| 在 App 里加一个作废列表 | 每个人都要更新 App 才生效 |
| 改成服务端在线校验 | 要架服务器，且断网就用不了 |

**十来个人的话建议不撤销** —— 发出去就发出去了。

---

## 七、安全边界（如实说明）

**这套机制防的是"转借"和"误传"，不是对抗逆向。**

原因：校验密钥编译在 App 里，懂逆向的人可以自己造码。

**能做到的**：挡住普通用户、防止一个码被多人用、可以设有效期。
**做不到的**：防止有人反编译 App 后自己生成码。

要做到后者，必须上服务端在线校验 —— 但那样就要架服务器，且断网不能用。
**目前的取舍是"离线可用"优先。**

---

## 八、常见问题

**Q：我换了优学院账号，原来的码还能用吗？**
不能。码和学号绑定，换账号要重新要一个。

**Q：我把码发到群里了，要紧吗？**
不要紧。别人填进去会被拒（不属于他的账号）。

**Q：页面上的列表没了，码还有效吗？**
有效。码本身自带签名，不依赖那个列表。

**Q：提示"签名校验失败"是什么意思？**
码被改过或复制不完整。重新复制一次完整的码。

**Q：填了对的码还是不解锁？**
检查两件事：① 优学院账号是否已绑定（要拿学号比对）；② 有效期是否已过。
