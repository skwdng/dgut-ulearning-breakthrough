## 一、顶层导航结构

```
┌────────────────────────────────────────────────┐
│   [首页]   [优学院]   [点餐]   [专属AI]          │  ← 顶部横向滑动栏
├────────────────────────────────────────────────┤
│                                                │
│               当前页内容                        │
│                                                │
└────────────────────────────────────────────────┘
```

- **首页在最左**，往右依次是优学院 / 点餐 / 专属AI
- **点击切换**（不跟手滑动）
- 选中项有胶囊填充 + 下划线
- 项数多时自动横向滚动，选中项自动滚入视野
- **没有底部 tab**

**代码位置**
- 顶部栏组件：`src/components/TopRail.tsx`
- 导航器与映射：`app/(tabs)/_layout.tsx`
- 四个页面：`app/(tabs)/index.tsx` `youxue.tsx` `food.tsx` `ai.tsx`

### ② 优学院 `app/(tabs)/youxue.tsx`

插件式切换栏（初始两个，解锁后三个）：

| 插件 | 状态 | 接口 |
|---|---|---|
| **课件** | ✅ 实测可用 | `/courseapi/course/content?ocId=&classId=&version=2` |
| **作业** | ✅ 实测可用 | `/courseapi/homeworks/student?ocId=&classId=&userId=` |
| **签到** | 🔒 需授权码解锁 | `/apps/newAttendance/*` |

**课件**：列出课程（实测 25 门）→ 点课程拉该课课件（实测总 5 个文件）。

**作业**：**跨课程聚合**，一次拉所有课的作业，带筛选（全部 / 未提交 / 进行中 / 已结束）+ 汇总（总数 / 未提交 / 进行中 / 平均分）。

实测规模：**25 门课 → 114 条作业，13 门课有作业，并发 5 耗时 0.3 秒**。

**作业的字段映射**（实测 90+ 条样本）：

| 字段 | 含义 |
|---|---|
| `homeworkTitle` | 标题 |
| `startTime` / `endTime` | 开始 / 截止 |
| `state` | `0`未开始 · `2`进行中 · `3`已结束 · `4`已批改 · `9`特殊 |
| `status` | **提交状态**：`2`未提交 · `3`已提交/已批改 |
| `score` | 得分 |
| `type` | `9`作业 · `3`测验 · `8`视频 |
| `publisher` | 发布教师 |

**作业排序**按"该不该现在处理"分档（不是简单按时间）：

```
0 进行中、未提交     ← 最该处理
1 进行中、已提交
2 已结束、未提交     ← 错过了要补
3 未开始            ← 同档按截止远近
4 已结束、已提交     ← 已完成沉底
```

**为什么需要这个排序**：实测「求是读书计划」有 54 条未开始的读书心得，截止在 **2029 年**。单纯按时间倒序会让这些长期任务占满列表顶部，把真正紧急的挤下去。

## 四、授权码（一人一码）

### 码的格式

```
LK1-5KYX2-LS3F2-222MY-LT6PR-QLWUL-PNW
```

- 前缀 `LK1`
- 载荷 13 字符（学号哈希 6 字节 + 有效期 2 字节）
- 签名 15 字符
- 字母表 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`（**去掉易混的 0/1/I/O，正好 32 个**）

### 一码一人怎么生效

```
码里嵌了「学号哈希」→ App 用当前登录学号算哈希 → 比对
  相同 → 解锁
  不同 → 拒绝（提示"不属于当前账号"）
```

**所以把码转给别人没用。** 已验证：50 组交叉测试，无一组错配。

### 生成方式

打开 `web/license-admin.html`（双击即可，不用联网）→ 填姓名 + 学号 → 生成。

细节见 `docs/license-code.md`。

### 关于「作业」接口的排查过程（供以后参考）

一开始找不到，走过弯路，记录下来：

```
1. 在 umobile JS 包里搜 homework  →  0 条命中
2. 怀疑在 PC 版 SPA（mooc/pc.html）→  下载后发现是教师端（coursePage/teaCourseFile）
3. 枚举路径时发现：
     /courseapi/homeworks  → 400 "Required Integer parameter 'classId' is not present"
     补上 classId 后        → 403 "只有课程管理员、教师或助教才能查看作业列表"
   说明 /courseapi/homeworks 是【教师接口】
4. 试同族路径 /courseapi/homeworks/student  → ✅ 200，拿到 6 条作业
```

**关键教训**：服务端返回 400 时会把**缺哪个参数**直接告诉你，这比盲猜快得多。
另外 `/courseapi/homeworks` 与 `/courseapi/homeworks/student` 只差一个后缀，
权限完全相反 —— 这类"同族不同权限"的路径值得优先试。

## 七、与旧结构的关系

| 旧 | 新 |
|---|---|
| 底部 tab（首页/日程/签到/待办/我的） | **顶部横向栏**（首页/优学院/点餐/专属AI） |
